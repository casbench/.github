# CASbench

CASbench develops reproducible benchmarks for computer algebra systems. Each run uses fixed inputs and records the system versions, limits, answers and checks so that a result can be inspected and reproduced.

[Benchmark site](https://casbench.github.io/) · [Suite and data](https://github.com/casbench/casbench.github.io) · [Methodology](https://casbench.github.io/methodology/) · [Disclosures](https://casbench.github.io/disclosures/)

We report verified coverage and timings alongside the cases and the verification methods. An unsolved or wrong case may hide a benchmark error; the input and output are available for review. The project welcomes corrections, reproducible runs and contributions through the benchmark repository.
